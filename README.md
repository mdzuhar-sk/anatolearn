# AnatoLearn

A mobile-friendly bilingual (English/Burmese) anatomy learning prototype.

## Lessons
- Heart and blood circulation
- Respiratory system and gas exchange
- Neurons and signal transmission

Each lesson includes a brief introduction, discussion, learning objectives, interactive diagram labels, and a short quiz. The diagrams are embedded SVG illustrations, so they do not depend on external image URLs or an internet connection. They are simplified schematic illustrations, not clinical anatomical models or rotatable 3D models.

## Publish with GitHub Pages
1. In the repository, open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then click **Save**.
4. Wait for GitHub Pages to deploy, then open the URL shown in Settings → Pages. Usually it is `https://mdzuhar-sk.github.io/anatolearn/`.

## Offline support
Open the published website once while online. The service worker caches the app shell for subsequent visits. Offline support requires HTTPS (GitHub Pages provides HTTPS) or localhost. Browser storage/cache may be cleared by the browser.

## Important
This is a prototype, not a validated educational intervention. A biology teacher should review scientific accuracy and Burmese terminology, and the lessons should be checked against the exact curriculum/textbook edition before research use. If testing with minors, obtain appropriate ethics approval, school permission, parental consent/assent, and follow safeguarding and privacy requirements.
